# pstack source and license

Adapted workflow: reproduce → failing regression → smallest evidence-backed fix
→ independent review → full verification and evidence handoff.

Author: Lauren Tan (poteto). Source read on 2026-10-12:
- https://github.com/cursor/plugins/tree/main/pstack
- https://github.com/cursor/plugins/blob/main/pstack/skills/poteto-mode/playbooks/bug-fix.md
- https://github.com/cursor/plugins/blob/main/pstack/skills/tdd/SKILL.md
- https://github.com/cursor/plugins/blob/main/pstack/LICENSE

These are mutable upstream links; no immutable upstream commit was pinned.
Only the workflow is adapted. Cursor Task/model/rules/cloud/loop routing, Grok
webhooks, plugin installation and PR/shipping steps are excluded. Local instructions
use the current Conductor Claude/Codex model and terminal tooling.
