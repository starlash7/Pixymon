## 선택지

### A. 현행 규칙 그대로
- 할 일: zero-X 검증기 구현 → R1(7일+) → R2(14일+, 100건 재생, 블라인드 2인) → R3.
- 소요: 최소 3주 이상, Anthropic 크레딧, 평가자 2명.
- 장점: 가장 안전. 단점: 1인 운영 기준으로 과하고, 그동안 계정은 조용하다.

### B. 간소화된 사람 승인 발행 (추천)
- 바꿀 규칙: zero-X 검증기·100건 재생·블라인드 2인을 첫 발행 조건에서 빼고, 아래로 대체한다.
  - 같은 epoch의 실제 shadow 초안 12건을 운영자가 `editorial:review`로 판정, 무수정 승인 ≥ 8건, 사실 오류 0.
  - 발행은 운영자가 승인한 글만, 하루 최대 1개, `editorial:publish` 경로(2단계 가드, STOP 파일 유지).
  - 롤백 기준은 현행 유지(사실 오류·중복·이상 글 1건이면 즉시 observe).
- 필요한 것: X API 키, live 초안용 모델 결정(Anthropic 크레딧 또는 Gemini live 허용 정책 변경).
- 소요: 샘플 12건이 모이는 대로(무료 한도 기준 1~2주).

### C. 코드 밖 수동 게시
